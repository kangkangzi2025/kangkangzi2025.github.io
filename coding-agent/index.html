About

Agent Notes is a curated map for understanding coding agents: how they plan, use tools, edit repositories, recover from failures, and remain trustworthy over long tasks.

Why These Readings

Each item is selected because it explains a core mechanism, a widely used system, or an evaluation signal that changes how coding agents are built.

What Notes Deliver

Every note distills the original source into reusable concepts, implementation patterns, failure modes, and practical takeaways for building agents.

How To Read

Start with the paper for context, then use the note as a guided reconstruction: what problem it solves, what design choices matter, and what to verify in code.
