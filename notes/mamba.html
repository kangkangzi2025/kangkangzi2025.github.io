1. Introduction

State Space Models (SSMs) have emerged as a compelling alternative to Transformers for sequence modeling. While Transformers achieve state-of-the-art performance across many domains, their quadratic attention complexity \(O(L^2)\) becomes prohibitive for long sequences. SSMs promise linear complexity \(O(L)\) while maintaining strong performance on tasks requiring long-range dependencies.

The evolution of modern SSMs can be traced through several key developments:

  • HiPPO (2020): Established the mathematical foundation for optimal memory compression
  • S4 (2022): Made SSMs computationally practical through structured parameterization
  • Mamba (2023): Introduced selectivity for content-aware processing
  • Mamba-2 (2024): Revealed the deep connection between SSMs and attention
Key Advantage: Dual Computation Modes

SSMs can be computed in two equivalent ways:

  • Recurrence: \(O(L)\) time, \(O(1)\) memory per step — ideal for autoregressive generation
  • Convolution: \(O(L \log L)\) time via FFT, parallelizable — ideal for training

This duality enables efficient training and efficient inference with the same model.

This note provides a comprehensive theoretical treatment of SSMs, from the continuous-time foundations through the latest architectural innovations. We emphasize the mathematical derivations that underlie these models' remarkable performance on long-range sequence modeling tasks.

2. State Space Models: Foundations

2.1 Continuous-Time Formulation

A linear time-invariant (LTI) state space model describes the evolution of a hidden state \(h(t) \in \mathbb{R}^N\) in response to an input signal \(u(t) \in \mathbb{R}\):

Definition: Continuous-Time SSM

The continuous-time state space model is defined by the system of differential equations:

\[\frac{dh(t)}{dt} = Ah(t) + Bu(t)\] \[y(t) = Ch(t) + Du(t)\]

where:

  • \(h(t) \in \mathbb{R}^N\) is the hidden state with dimension \(N\) (state size)
  • \(u(t) \in \mathbb{R}\) is the scalar input signal
  • \(y(t) \in \mathbb{R}\) is the scalar output signal
  • \(A \in \mathbb{R}^{N \times N}\) is the state transition matrix
  • \(B \in \mathbb{R}^{N \times 1}\) is the input projection matrix
  • \(C \in \mathbb{R}^{1 \times N}\) is the output projection matrix
  • \(D \in \mathbb{R}\) is the feedthrough (skip connection) scalar

The state dimension \(N\) controls the model's capacity to store information about the input history. Larger \(N\) allows more complex temporal patterns but increases computation.

2.2 Solution via Matrix Exponential

The linear ODE has a closed-form solution. Given initial state \(h(0)\), the state at time \(t\) is:

Theorem: General Solution of Linear ODE
\[h(t) = e^{At}h(0) + \int_0^t e^{A(t-\tau)}Bu(\tau)d\tau\]

The first term represents the autonomous evolution of the initial state, decaying according to the eigenvalues of \(A\). The second term is a convolution of the input with the impulse response \(e^{A\tau}B\).

Proof sketch: The homogeneous equation \(dh/dt = Ah\) has solution \(h(t) = e^{At}h(0)\). Using variation of parameters, we substitute \(h(t) = e^{At}v(t)\), yielding \(dv/dt = e^{-At}Bu(t)\), which integrates to the convolution integral.

2.3 Stability Analysis

The stability of the SSM depends entirely on the eigenvalues of \(A\):

Theorem: SSM Stability

A continuous-time LTI system is:

  • Asymptotically stable if all eigenvalues of \(A\) have negative real parts: \(\text{Re}(\lambda_i) < 0\) for all \(i\)
  • Marginally stable if all eigenvalues have non-positive real parts and those on the imaginary axis are simple
  • Unstable if any eigenvalue has positive real part

For sequence modeling, we typically require stability: the state should not grow unboundedly. This constrains the initialization of \(A\). The HiPPO framework provides principled constructions that satisfy stability while enabling long-range memory.

2.4 Transfer Function Representation

Taking the Laplace transform of the SSM equations (with zero initial conditions):

\[sH(s) = AH(s) + BU(s)\] \[Y(s) = CH(s) + DU(s)\]

Solving for the transfer function \(G(s) = Y(s)/U(s)\):

\[G(s) = C(sI - A)^{-1}B + D\]

The transfer function characterizes the input-output behavior in the frequency domain. The poles of \(G(s)\) are the eigenvalues of \(A\), confirming that stability is determined by these eigenvalues.

3. Discretization Methods

To apply continuous-time SSMs to discrete sequences (e.g., tokenized text), we must discretize the system. The discretization step size \(\Delta\) becomes a learnable parameter.

3.1 Zero-Order Hold (ZOH)

The ZOH discretization assumes the input is constant over each time interval \([k\Delta, (k+1)\Delta)\):

Definition: Zero-Order Hold Discretization

Starting from the continuous solution and assuming \(u(\tau) = u_k\) for \(\tau \in [k\Delta, (k+1)\Delta)\):

\[\bar{A} = e^{\Delta A}\] \[\bar{B} = \left(\int_0^{\Delta} e^{A\tau}d\tau\right) B = A^{-1}(e^{\Delta A} - I)B\]

The discrete recurrence becomes:

\[h_k = \bar{A}h_{k-1} + \bar{B}u_k\] \[y_k = Ch_k + Du_k\]

The ZOH discretization preserves the eigenvalue structure: if \(\lambda\) is an eigenvalue of \(A\), then \(e^{\Delta\lambda}\) is the corresponding eigenvalue of \(\bar{A}\). This ensures that stability is preserved under discretization.

3.2 Bilinear Transform (Tustin's Method)

An alternative discretization that better preserves frequency-domain properties:

Definition: Bilinear Discretization

The bilinear transform substitutes \(s = \frac{2}{\Delta}\frac{z-1}{z+1}\):

\[\bar{A} = \left(I - \frac{\Delta}{2}A\right)^{-1}\left(I + \frac{\Delta}{2}A\right)\] \[\bar{B} = \left(I - \frac{\Delta}{2}A\right)^{-1}\Delta B\] \[\bar{C} = C\left(I - \frac{\Delta}{2}A\right)^{-1}\]

The bilinear transform maps the left half of the \(s\)-plane (stable continuous eigenvalues) to the interior of the unit circle (stable discrete eigenvalues), guaranteeing that stable continuous systems remain stable after discretization.

3.3 Euler Discretization

The simplest discretization uses forward Euler:

\[\bar{A} = I + \Delta A, \quad \bar{B} = \Delta B\]

While computationally cheap, Euler discretization can introduce instability for poorly conditioned \(A\) or large \(\Delta\). It is primarily useful for theoretical analysis.

3.4 The Convolution View

Unrolling the discrete recurrence reveals that the output is a convolution:

Theorem: SSM as Convolution

The output sequence \(\{y_k\}\) can be computed as:

\[y = K * u + Du\]

where \(*\) denotes discrete convolution and the kernel \(K\) is:

\[K = (C\bar{B}, C\bar{A}\bar{B}, C\bar{A}^2\bar{B}, \ldots, C\bar{A}^{L-1}\bar{B})\]

Proof: Unrolling the recurrence:

\[h_k = \bar{A}^k h_0 + \sum_{j=0}^{k-1} \bar{A}^{k-1-j}\bar{B}u_j\]

With \(h_0 = 0\), the output \(y_k = Ch_k = \sum_{j=0}^{k-1} C\bar{A}^{k-1-j}\bar{B}u_j\), which is exactly a convolution with kernel \(K_i = C\bar{A}^i\bar{B}\).

This kernel can be precomputed and applied via FFT for \(O(L \log L)\) training complexity, enabling efficient parallelization on GPUs.

4. HiPPO: Optimal Memory Compression

HiPPO (High-order Polynomial Projection Operators) provides a principled framework for constructing the state matrix \(A\). The key insight is that the hidden state should optimally compress the input history.

4.1 The Memory Compression Problem

Given an input signal \(u(\tau)\) for \(\tau \in [0, t]\), we want the state \(h(t)\) to encode a compressed representation. Specifically, we seek coefficients \(c_n(t)\) such that:

\[u(\tau) \approx \sum_{n=0}^{N-1} c_n(t) \cdot p_n(\tau; t)\]

where \(\{p_n\}\) is a polynomial basis. Different choices of basis and weighting measure lead to different HiPPO variants.

4.2 HiPPO-LegS (Legendre Scaled)

The most successful variant uses Legendre polynomials with a sliding window measure that weights all past history uniformly:

Theorem: HiPPO-LegS Matrix

For the measure \(\mu^{(t)}(\tau) = \frac{1}{t}\mathbf{1}_{[0,t]}(\tau)\) (uniform on history), the optimal projection onto Legendre polynomials yields:

\[A_{nk} = -\begin{cases} (2n+1)^{1/2}(2k+1)^{1/2} & \text{if } n > k \\ n+1 & \text{if } n = k \\ 0 & \text{if } n < k \end{cases}\] \[B_n = (2n+1)^{1/2}\]

This lower-triangular structure ensures computational efficiency while enabling unbounded memory of the entire input history.

The remarkable property is that \(h(t)\) contains all information needed to reconstruct \(u(\tau)\) for all \(\tau \leq t\), compressed into \(N\) coefficients.

4.3 HiPPO-LagT (Laguerre Translated)

An alternative using exponentially decaying memory:

\[\mu^{(t)}(\tau) = e^{-(t-\tau)}\mathbf{1}_{(-\infty,t]}(\tau)\]

This leads to the matrix:

\[A_{nk} = \begin{cases} -1 & \text{if } n = k \\ -1 & \text{if } n = k + 1 \\ 0 & \text{otherwise} \end{cases}\]

The bidiagonal structure is extremely efficient but provides exponentially decaying rather than uniform memory.

4.4 Theoretical Guarantees

HiPPO matrices enjoy several theoretical properties:

  • Optimality: They minimize the projection error onto polynomial bases under the specified measure
  • Stability: All eigenvalues have negative or zero real parts
  • Bounded operator norm: Enables stable training dynamics
  • Time-scale invariance: Performance is independent of sequence length when properly initialized
Example: Approximation Quality

With \(N = 64\) HiPPO coefficients, we can approximate smooth functions over windows of length \(T\) with error \(O(T^{-64})\). This exponential decay in approximation error explains why moderate state sizes suffice for long sequences.

5. S4: Structured State Spaces

S4 (Structured State Space Sequence model) makes SSMs practical by addressing the computational challenges of naive implementations.

5.1 Computational Challenge

Naively computing the SSM kernel requires:

  • Computing \(e^{\Delta A}\) — expensive for dense \(A\)
  • Computing powers \(\bar{A}^k\) for \(k = 0, \ldots, L-1\) — \(O(N^2 L)\) operations

For sequence length \(L = 16384\) and state size \(N = 64\), this becomes prohibitive.

5.2 NPLR Parameterization

S4 introduces the Normal Plus Low-Rank (NPLR) decomposition:

Definition: NPLR Structure
\[A = V\Lambda V^* - PQ^*\]

where:

  • \(\Lambda \in \mathbb{C}^{N \times N}\) is diagonal (normal part)
  • \(V\) is the change-of-basis matrix
  • \(P, Q \in \mathbb{C}^{N \times r}\) are low-rank factors with \(r \ll N\)

The key insight is that HiPPO matrices are exactly NPLR with rank \(r = 1\) or \(r = 2\). This structure enables efficient computation via the Woodbury identity.

5.3 Efficient Kernel Computation

With the NPLR structure, the kernel can be computed in \(O(N + L)\) time:

Theorem: S4 Kernel Algorithm

Define the generating function:

\[\hat{K}(\Omega) = \sum_{k=0}^{L-1} K_k \Omega^k = \tilde{C}(I - \bar{A}\Omega)^{-1}\bar{B}\]

Evaluating at roots of unity \(\Omega = e^{2\pi i/L}\) gives the DFT of \(K\), which can be inverted to obtain the kernel. Using the NPLR structure and Woodbury:

\[(I - \bar{A}\Omega)^{-1} = (I - \bar{\Lambda}\Omega)^{-1} + \text{low-rank correction}\]

The diagonal inverse is \(O(N)\), and the low-rank correction adds \(O(r^2N)\).

5.4 S4D: Diagonal State Spaces

A simplified variant uses purely diagonal \(A\):

\[A = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_N)\]

This reduces the SSM to \(N\) independent scalar systems:

\[\frac{dh_n}{dt} = \lambda_n h_n + B_n u\]
S4D Initialization

The diagonal elements are initialized as:

\[\lambda_n = -\frac{1}{2} + i\pi n, \quad n = 1, \ldots, N\]

This creates a "frequency comb" that captures oscillations at different frequencies. The negative real part ensures stability, while the imaginary parts create oscillations.

S4D achieves similar performance to S4 with much simpler implementation, making it the basis for most subsequent work including Mamba.

6. Frequency Domain Analysis

6.1 SSM as a Filter

From the signal processing perspective, an SSM is a linear filter. The frequency response is obtained by evaluating the transfer function on the imaginary axis:

\[H(\omega) = G(i\omega) = C(i\omega I - A)^{-1}B + D\]

The magnitude \(|H(\omega)|\) describes how the SSM amplifies or attenuates each frequency component.

6.2 Pole-Zero Analysis

The poles of the transfer function (eigenvalues of \(A\)) determine:

  • Resonant frequencies: Imaginary parts of poles create peaks in \(|H(\omega)|\)
  • Bandwidth: Real parts determine how sharply tuned the resonances are
  • Long-range memory: Poles close to the imaginary axis create slow decay
Theorem: Memory Length

The effective memory length of an SSM mode with eigenvalue \(\lambda = \sigma + i\omega\) (where \(\sigma < 0\)) is approximately:

\[\tau_{memory} \approx \frac{1}{|\sigma|}\]

Modes with \(\sigma\) close to zero have long memory; those with large \(|\sigma|\) decay quickly.

6.3 Connection to Convolution Kernels

The impulse response of the SSM (the inverse Fourier transform of \(H(\omega)\)) is:

\[h(t) = Ce^{At}B \cdot \mathbf{1}_{t \geq 0}\]

For diagonal \(A = \text{diag}(\lambda_n)\):

\[h(t) = \sum_{n=1}^N C_n B_n e^{\lambda_n t}\]

Each mode contributes a decaying oscillation. The superposition creates complex temporal patterns that can capture long-range dependencies.

6.4 Comparison with Attention

Aspect SSM Attention
Frequency response Fixed (learned during training) Dynamic (computed per input)
Memory access Compressed in state \(h\) Explicit via KV cache
Computational pattern Linear in sequence length Quadratic (softmax attention)
Content-based routing None (in LTI systems) Full (attention weights)

7. Mamba: Selective State Spaces

Mamba addresses the fundamental limitation of LTI systems: they cannot perform content-based reasoning. The solution is selectivity—making the SSM parameters depend on the input.

7.1 The Selectivity Principle

Consider a simple task: "copy the token that appears after 'KEY'". An LTI system cannot solve this—it treats all positions identically. Selectivity enables content-aware processing:

Definition: Selective SSM

In a selective SSM, the parameters become input-dependent functions:

\[B_t = \text{Linear}_B(x_t) \in \mathbb{R}^N\] \[C_t = \text{Linear}_C(x_t) \in \mathbb{R}^N\] \[\Delta_t = \text{softplus}(\text{Linear}_\Delta(x_t) + \text{broadcast}(\Delta_{bias})) \in \mathbb{R}^+\]

The discretized parameters are:

\[\bar{A}_t = \exp(\Delta_t A)\] \[\bar{B}_t = \Delta_t B_t\]

Note that \(A\) remains fixed (diagonal and learned), while \(B, C, \Delta\) are input-dependent.

7.2 Interpretation of \(\Delta\)

The step size \(\Delta_t\) controls the "gate" between ignoring and incorporating the input:

  • \(\Delta_t \to 0\): \(\bar{A}_t \to I\), \(\bar{B}_t \to 0\) — ignore input, preserve state
  • \(\Delta_t \to \infty\): \(\bar{A}_t \to 0\) — reset state, focus on current input
Example: Selective Copying

For the "copy after KEY" task, the model can learn:

  • Small \(\Delta\) on most tokens (ignore, maintain state)
  • Large \(\Delta\) on tokens following "KEY" (capture into state)
  • Large \(C\) at the output position (read from state)

7.3 The Mamba Block

Mamba integrates the selective SSM into a residual block:

  1. Linear projection: \(x \to (z, x')\) where \(z\) is the gate and \(x'\) feeds the SSM
  2. Convolution: Short 1D convolution on \(x'\) for local context
  3. Selective SSM: Apply the input-dependent state space model
  4. Gating: \(y = \sigma(z) \odot \text{SSM}(x')\)
  5. Linear projection: Project back to model dimension

7.4 Loss of Convolution Mode

Selectivity breaks the convolution view: since parameters change per position, we cannot precompute a single kernel. This necessitates the recurrent mode for both training and inference, requiring hardware-aware optimizations.

8. Hardware-Aware Implementation

8.1 Memory Hierarchy Challenge

Modern GPUs have a severe memory bandwidth bottleneck:

  • HBM (High Bandwidth Memory): Large (80GB) but slow (~2 TB/s)
  • SRAM (on-chip): Fast (~20 TB/s) but small (~20MB)

Naive selective SSM implementation would require \(O(BLDN)\) HBM reads/writes per layer (B=batch, L=length, D=dimension, N=state size), bottlenecking on bandwidth.

8.2 Kernel Fusion

Mamba fuses the entire selective SSM computation into a single GPU kernel:

Fused Selective Scan

The algorithm:

  1. Load input \(x\) and parameters from HBM to SRAM once
  2. Compute \(B_t, C_t, \Delta_t\) projections in SRAM
  3. Discretize \(\bar{A}_t, \bar{B}_t\) in SRAM
  4. Run the recurrence \(h_t = \bar{A}_t h_{t-1} + \bar{B}_t x_t\) in SRAM
  5. Compute output \(y_t = C_t h_t\) in SRAM
  6. Write output back to HBM once

This reduces HBM accesses from \(O(BLDN)\) to \(O(BLD + BDN)\).

8.3 Parallel Scan Algorithm

The recurrence \(h_t = \bar{A}_t h_{t-1} + \bar{B}_t x_t\) appears sequential, but can be parallelized using the associative scan (prefix sum) algorithm:

Theorem: Associativity of Linear Recurrence

Define the binary operator \(\bullet\) on pairs \((a, b)\):

\[(a_1, b_1) \bullet (a_2, b_2) = (a_1 a_2, a_2 b_1 + b_2)\]

Then \((a_1, b_1) \bullet (a_2, b_2) \bullet \cdots \bullet (a_t, b_t) = (\prod_i a_i, h_t)\) where \(h_t\) is the state from the linear recurrence with \(a_i = \bar{A}_i\), \(b_i = \bar{B}_i x_i\).

Associativity enables \(O(\log L)\) parallel depth via prefix scan.

8.4 Recomputation Strategy

To reduce memory during backpropagation, Mamba recomputes intermediate states from inputs rather than storing them. This trades computation for memory:

  • Forward pass: Compute normally, discard intermediate states
  • Backward pass: Recompute states, then compute gradients

The fast fused kernel makes this recomputation cheaper than the memory cost of storing all states.

9. Mamba-2: State Space Duality

Mamba-2 reveals a deep mathematical connection between SSMs and attention, enabling further architectural and computational improvements.

9.1 State Space Duality (SSD)

The key insight is that a structured SSM with scalar hidden state can be written in quadratic (attention-like) form:

Theorem: SSM-Attention Duality

Consider a scalar selective SSM with recurrence:

\[h_t = a_t h_{t-1} + b_t x_t, \quad y_t = c_t h_t\]

The output can be written as:

\[y_t = \sum_{s=1}^{t} c_t b_s x_s \prod_{r=s+1}^{t} a_r\]

Defining \(L_{ts} = \prod_{r=s+1}^{t} a_r\) (a lower-triangular mask), this becomes:

\[Y = (L \odot CB^T) X\]

This is exactly a form of linear attention with a structured causal mask \(L\).

9.2 Multi-Head Structure

Mamba-2 expands the state dimension with a multi-head structure:

  • State heads: Multiple independent scalar SSMs per channel
  • Head dimension: Size of the state per head (typically 64-128)

This mirrors the multi-head structure in attention, allowing the model to maintain multiple parallel "memory streams."

9.3 Block-Wise Computation

The SSD framework enables a hybrid algorithm:

SSD Block Algorithm

Partition the sequence into blocks of size \(Q\):

  • Intra-block: Use the quadratic (attention) form — \(O(Q^2)\) per block, parallelizable
  • Inter-block: Use the recurrent (SSM) form — \(O(L/Q)\) sequential steps

With \(Q = O(\sqrt{L})\), total complexity is \(O(L\sqrt{L})\) — subquadratic in \(L\) while fully utilizing parallel hardware.

9.4 Structured Masked Attention

The mask matrix \(L\) in SSD has special structure. For \(a_t = a\) (constant), \(L\) is a Toeplitz matrix:

\[L_{ts} = a^{t-s} \quad \text{for } s \leq t\]

More generally, the mask encodes the "forgetting pattern" of the SSM. This connects to recent work on efficient attention with structured sparsity.

9.5 Tensor Cores Utilization

The quadratic form in SSD maps naturally to matrix multiplication, enabling use of Tensor Cores on modern GPUs. Mamba-2 achieves 2-8× speedup over Mamba-1 primarily through better hardware utilization.

10. Architectural Variants

10.1 Jamba: Hybrid SSM-Attention

AI21's Jamba interleaves Mamba and attention layers:

  • Ratio: Typically 7 Mamba layers per 1 attention layer
  • Attention provides global, content-based reasoning
  • Mamba handles efficient long-range dependencies

10.2 Vision Mamba (ViM)

Adapting Mamba for vision requires handling 2D structure:

  • Bidirectional scanning: Process patches left-to-right and right-to-left
  • Multi-directional: Also scan top-to-bottom, diagonal, etc.
  • Patch embedding: Like ViT, divide image into patches

10.3 Griffin and Hawk

DeepMind's variants introduce:

  • Real-Gated Linear Recurrence (Griffin): Simplified gating mechanism
  • Hawk: Combines linear recurrence with local attention

10.4 RWKV

RWKV (Receptance Weighted Key Value) is a parallel development with similar goals:

\[wkv_t = \frac{\sum_{i=1}^{t-1} e^{-(t-1-i)w + k_i} v_i + e^{u+k_t} v_t}{\sum_{i=1}^{t-1} e^{-(t-1-i)w + k_i} + e^{u+k_t}}\]

This can be viewed as an SSM with softmax normalization, bridging SSM and attention concepts.

11. Connections to Other Models

11.1 Relation to RNNs

SSMs are linear RNNs with structured state transitions:

Aspect Traditional RNN SSM
Transition Nonlinear \(h_t = \tanh(Wh_{t-1} + Ux_t)\) Linear \(h_t = Ah_{t-1} + Bx_t\)
Gradient flow Vanishing/exploding gradients Stable via eigenvalue control
Parallel training Difficult Possible via convolution view
Initialization Random Principled (HiPPO)

11.2 Relation to Linear Attention

Linear attention replaces softmax with a kernel feature map:

\[\text{Attn}(Q, K, V) = \phi(Q)(\phi(K)^T V)\]

This can be computed recurrently by maintaining \(S_t = \sum_{i=1}^t \phi(k_i)v_i^T\). SSD shows this is exactly an SSM with specific structure.

11.3 Relation to Convolutions

Time-invariant SSMs are equivalent to global convolutions:

  • SSM kernel length = sequence length (global receptive field)
  • Kernel is structured (exponentially decaying oscillations)
  • HiPPO provides principled kernel design for long-range dependencies

11.4 Relation to Control Theory

SSMs originate in control theory, where they model physical systems:

  • Controllability: Can all states be reached via input?
  • Observability: Can state be inferred from output?
  • Stability: Does the system return to equilibrium?

These classical concepts provide theoretical grounding for SSM design choices.

The Broader Picture

SSMs, attention, and recurrent models form a connected family:

  • Attention = SSM with infinite state (storing all past KV pairs)
  • Linear attention = SSM with finite state and specific structure
  • Mamba = Selective (input-dependent) SSM
  • RNNs = Nonlinear SSMs without structured initialization

Understanding these connections guides architecture design and explains when each approach excels.
