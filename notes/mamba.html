1. Introduction

State Space Models (SSMs) offer a compelling alternative to Transformers for sequence modeling. While Transformers achieve state-of-the-art performance, their quadratic attention complexity \(O(L^2)\) becomes prohibitive for long sequences. SSMs promise linear complexity \(O(L)\) while maintaining strong performance.

Key Advantage

SSMs can be computed as either a recurrence (for autoregressive generation) or a convolution (for parallel training). This dual view enables efficient training and efficient inference.

This note traces the evolution from classical SSMs through S4 to Mamba, focusing on the theoretical foundations that enable their success.

2. State Space Models

2.1 Continuous-Time Formulation

A linear time-invariant (LTI) state space model is defined by:

Definition: Continuous SSM
\[\frac{dh(t)}{dt} = Ah(t) + Bu(t)\] \[y(t) = Ch(t) + Du(t)\]

where \(h(t) \in \mathbb{R}^N\) is the hidden state, \(u(t) \in \mathbb{R}\) is the input, \(y(t) \in \mathbb{R}\) is the output, and \(A \in \mathbb{R}^{N \times N}\), \(B \in \mathbb{R}^{N \times 1}\), \(C \in \mathbb{R}^{1 \times N}\), \(D \in \mathbb{R}\) are parameters.

2.2 Solution via Matrix Exponential

The solution to the ODE is:

\[h(t) = e^{At}h(0) + \int_0^t e^{A(t-\tau)}Bu(\tau)d\tau\]

This shows that the state \(h(t)\) is a linear combination of the input history, weighted by the matrix exponential \(e^{A(t-\tau)}\).

3. Discretization

To apply SSMs to discrete sequences, we discretize with step size \(\Delta\):

Definition: Zero-Order Hold (ZOH) Discretization

Assuming the input is constant over each interval:

\[\bar{A} = e^{\Delta A}\] \[\bar{B} = (\Delta A)^{-1}(e^{\Delta A} - I) \cdot \Delta B\]

The discrete recurrence becomes: \(h_k = \bar{A}h_{k-1} + \bar{B}u_k\)

3.1 Bilinear Transform

An alternative discretization that preserves stability:

\[\bar{A} = (I - \Delta A/2)^{-1}(I + \Delta A/2)\] \[\bar{B} = (I - \Delta A/2)^{-1}\Delta B\]

3.2 Convolution View

The discretized SSM can be computed as a convolution:

\[y = K * u \quad \text{where} \quad K = (C\bar{B}, C\bar{A}\bar{B}, C\bar{A}^2\bar{B}, \ldots)\]

This kernel \(K\) can be precomputed and applied via FFT for \(O(L \log L)\) training.

4. HiPPO Matrices

The choice of matrix \(A\) is crucial. HiPPO (High-order Polynomial Projection Operators) provides principled constructions:

Theorem: HiPPO-LegS

For the Legendre measure (uniform weighting of history), the optimal \(A\) matrix is:

\[A_{nk} = -\begin{cases} (2n+1)^{1/2}(2k+1)^{1/2} & \text{if } n > k \\ n+1 & \text{if } n = k \\ 0 & \text{if } n < k \end{cases}\]

This matrix projects the input history onto Legendre polynomial coefficients.

HiPPO matrices have the remarkable property that the hidden state \(h(t)\) optimally compresses the entire input history \(u(\tau)\) for \(\tau \leq t\).

5. S4 Architecture

S4 (Structured State Space Sequence model) makes SSMs practical by addressing computational challenges:

5.1 Diagonal Plus Low-Rank

Computing \(e^{\Delta A}\) is expensive for dense \(A\). S4 parameterizes:

\[A = \Lambda - PQ^*\]

where \(\Lambda\) is diagonal. This enables efficient computation via the Woodbury identity.

5.2 S4D: Diagonal SSM

A simplified variant uses purely diagonal \(A\):

\[A = \text{diag}(a_1, a_2, \ldots, a_N)\]

This reduces to \(N\) independent scalar SSMs, enabling trivial parallelization.

6. Mamba: Selective SSM

Mamba introduces selectivity: the parameters \(B\), \(C\), and \(\Delta\) become input-dependent:

Definition: Selective SSM
\[B_t = \text{Linear}_B(x_t)\] \[C_t = \text{Linear}_C(x_t)\] \[\Delta_t = \text{softplus}(\text{Linear}_\Delta(x_t))\]

The model can now selectively remember or forget based on the input content.

6.1 Why Selectivity Matters

Consider the task: "copy the token after 'KEY'". A time-invariant SSM cannot solve this—it treats all positions equally. Selectivity allows the model to:

  • Increase \(\Delta\) (open the gate) when seeing important tokens
  • Decrease \(\Delta\) (close the gate) to ignore irrelevant tokens

6.2 Hardware-Aware Algorithm

Selectivity breaks the convolution view (parameters change per position). Mamba uses a parallel scan algorithm that achieves:

  • \(O(L)\) time complexity
  • Efficient GPU memory access patterns
  • Kernel fusion to minimize memory I/O

7. Mamba-2 and SSD

Mamba-2 reveals a deep connection between SSMs and attention:

Theorem: SSM-Attention Duality

A selective SSM with scalar state and \(\Delta_t = 1\) is equivalent to linear attention with a causal mask. The hidden state corresponds to the cumulative key-value product.

7.1 State Space Duality (SSD)

SSD provides two equivalent views:

SSM View Attention View
Recurrence: \(h_t = Ah_{t-1} + Bx_t\) Matrix: \(Y = (L \odot QK^\top)V\)
Sequential, constant memory Parallel, quadratic memory

7.2 Block-wise Algorithm

Mamba-2 chunks the sequence and uses the attention view within blocks, SSM view across blocks. This achieves both parallelism and linear memory.

8. Connections to Other Models

8.1 Relation to RNNs

SSMs are linear RNNs with structured state transitions. Unlike vanilla RNNs, the continuous-time parameterization ensures stability and enables principled initialization (HiPPO).

8.2 Relation to Attention

Mamba-2 shows SSMs and linear attention are mathematically equivalent. Standard softmax attention can be viewed as an SSM with infinite state dimension.

8.3 Relation to Convolutions

Time-invariant SSMs are global convolutions with structured kernels. The HiPPO framework provides a principled way to design these kernels for long-range dependencies.
