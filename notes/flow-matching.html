1. Introduction

Generative modeling has witnessed remarkable progress in recent years, with diffusion models achieving state-of-the-art results in image, audio, and video generation. However, the theoretical foundations of diffusion models are deeply tied to stochastic differential equations (SDEs), which can be conceptually complex and computationally expensive.

Flow Matching offers an elegant alternative. Instead of learning to reverse a noising process, Flow Matching directly learns a velocity field that transports samples from a simple prior distribution (e.g., Gaussian noise) to the data distribution. This is achieved through ordinary differential equations (ODEs), which are deterministic and often more efficient to solve.

Key Insight

Flow Matching simplifies generative modeling by learning a vector field that defines a probability flow ODE. The training objective is regression: predict the velocity at each point in space-time.

2. Background: Continuous Normalizing Flows

A Continuous Normalizing Flow (CNF) defines a time-dependent transformation of random variables. Given a time-dependent velocity field \(v_t: \mathbb{R}^d \to \mathbb{R}^d\), we can define a flow \(\phi_t\) via the ODE:

\[ \frac{d\phi_t(x)}{dt} = v_t(\phi_t(x)), \quad \phi_0(x) = x \]

This flow transports a probability distribution \(p_0\) at time \(t=0\) to a distribution \(p_t\) at time \(t\). The key equation governing this evolution is the continuity equation:

\[ \frac{\partial p_t}{\partial t} + \nabla \cdot (p_t v_t) = 0 \]
Definition: Probability Path

A probability path is a time-indexed family of probability distributions \(\{p_t\}_{t \in [0,1]}\) that interpolates between a prior \(p_0\) and a target distribution \(p_1\) (the data distribution).

3. Flow Matching

The goal of Flow Matching is to learn a velocity field \(v_\theta\) such that the induced flow transforms samples from \(p_0\) to \(p_1\). The Flow Matching objective is:

\[ \mathcal{L}_{\text{FM}}(\theta) = \mathbb{E}_{t \sim \mathcal{U}[0,1], x \sim p_t} \left[ \| v_\theta(x, t) - u_t(x) \|^2 \right] \]

where \(u_t(x)\) is the target velocity field that generates the probability path \(p_t\). However, computing \(u_t(x)\) directly is intractable because it requires knowing the marginal density \(p_t\).

The Challenge

Given a probability path \(p_t\), the velocity field that generates it is not unique. Moreover, computing the marginal \(p_t\) and the corresponding velocity requires solving complex integrals. This is where Conditional Flow Matching comes to the rescue.

4. Conditional Flow Matching

The key insight of Conditional Flow Matching (CFM) is to construct the probability path and velocity field conditionally on individual data points. This sidesteps the need to compute intractable marginals.

4.1 Conditional Probability Path

For each data point \(x_1 \sim p_{\text{data}}\), we define a conditional probability path \(p_t(x | x_1)\) that interpolates between the prior \(p_0\) and a distribution concentrated at \(x_1\). The simplest choice is a Gaussian path:

\[ p_t(x | x_1) = \mathcal{N}(x; \mu_t(x_1), \sigma_t^2 I) \]

where \(\mu_t\) and \(\sigma_t\) define how the mean and variance evolve over time.

4.2 Linear Interpolation

A particularly simple and effective choice is linear interpolation:

\[ x_t = (1 - t) x_0 + t x_1 \]

where \(x_0 \sim \mathcal{N}(0, I)\) is a noise sample and \(x_1\) is a data sample. This corresponds to:

  • \(\mu_t(x_1) = t \cdot x_1\)
  • \(\sigma_t = 1 - t\)

4.3 Conditional Velocity Field

For the linear interpolation path, the conditional velocity field is remarkably simple:

\[ u_t(x | x_1) = \frac{dx_t}{dt} = x_1 - x_0 \]

This is just the displacement from the noise sample to the data sample!

Theorem: CFM Objective Equivalence

The Conditional Flow Matching objective:

\[ \mathcal{L}_{\text{CFM}}(\theta) = \mathbb{E}_{t, x_0, x_1} \left[ \| v_\theta(x_t, t) - (x_1 - x_0) \|^2 \right] \]

has the same gradient as the Flow Matching objective \(\mathcal{L}_{\text{FM}}\), making it a valid training objective.

4.4 Training Algorithm

The CFM training procedure is elegantly simple:

  1. Sample a data point \(x_1 \sim p_{\text{data}}\)
  2. Sample noise \(x_0 \sim \mathcal{N}(0, I)\)
  3. Sample time \(t \sim \mathcal{U}[0, 1]\)
  4. Compute interpolation: \(x_t = (1-t) x_0 + t x_1\)
  5. Compute target velocity: \(v = x_1 - x_0\)
  6. Update \(\theta\) to minimize \(\| v_\theta(x_t, t) - v \|^2\)

5. Optimal Transport Paths

The linear interpolation path is not arbitrary—it is connected to optimal transport. When we pair \(x_0\) with \(x_1\) independently (as in the training algorithm above), the resulting flow approximates the optimal transport map between \(p_0\) and \(p_1\).

Why Optimal Transport?

Optimal transport paths are geodesics in the space of probability distributions (under the Wasserstein metric). They represent the most efficient way to transform one distribution into another, leading to straighter trajectories and faster sampling.

6. Implementation

Here is a minimal PyTorch implementation of CFM training: 

import torch
import torch.nn as nn

class VelocityNetwork(nn.Module):
    def __init__(self, dim, hidden_dim=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(dim + 1, hidden_dim),  # +1 for time
            nn.SiLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.SiLU(),
            nn.Linear(hidden_dim, dim)
        )
    
    def forward(self, x, t):
        # t: (batch,) -> (batch, 1)
        t = t.unsqueeze(-1) if t.dim() == 1 else t
        return self.net(torch.cat([x, t], dim=-1))

def cfm_loss(model, x1, sigma_min=0.001):
    """Conditional Flow Matching loss."""
    batch_size = x1.shape[0]
    
    # Sample noise and time
    x0 = torch.randn_like(x1)
    t = torch.rand(batch_size, device=x1.device)
    
    # Linear interpolation
    t_expand = t.view(-1, *([1] * (x1.dim() - 1)))
    x_t = (1 - t_expand) * x0 + t_expand * x1
    
    # Target velocity
    target = x1 - x0
    
    # Predict and compute loss
    pred = model(x_t, t)
    return ((pred - target) ** 2).mean()

def sample(model, shape, steps=100, device='cuda'):
    """Generate samples using Euler integration."""
    x = torch.randn(shape, device=device)
    dt = 1.0 / steps
    
    for i in range(steps):
        t = torch.full((shape[0],), i * dt, device=device)
        v = model(x, t)
        x = x + v * dt
    
    return x

6.1 Sampling

To generate samples, we solve the ODE from \(t=0\) to \(t=1\):

\[ x_{t + \Delta t} = x_t + v_\theta(x_t, t) \cdot \Delta t \]

This can be done with any ODE solver (Euler, RK4, adaptive solvers, etc.). The deterministic nature of the ODE makes sampling efficient and reproducible.
