1. Introduction

Standard diffusion models operate on continuous data, adding Gaussian noise to images, audio, or other real-valued signals. However, much of the world's data is fundamentally discrete: text, code, molecular structures, DNA sequences, and symbolic representations. Applying diffusion to discrete data requires rethinking the corruption process entirely.

Key Challenge

We cannot add Gaussian noise to discrete tokens—there is no meaningful "noisy version" of the word "cat" in continuous space. Instead, we must define a transition process over discrete states that gradually destroys information while remaining tractable.

Three major frameworks have emerged for discrete diffusion:

  • D3PM (2021): General transition matrices with various corruption strategies
  • MDLM (2024): Masked diffusion that connects to BERT-style training
  • SEDD (2024): Score matching adapted for discrete spaces

These approaches have shown remarkable success for language modeling, achieving competitive perplexity with autoregressive models while enabling parallel generation and flexible conditioning. This note provides a comprehensive theoretical treatment of each framework.

2. Background: Continuous Diffusion

Before diving into discrete diffusion, we briefly review the continuous case to establish notation and highlight the key concepts that must be adapted.

2.1 Forward Process

In continuous diffusion, the forward process adds Gaussian noise:

\[q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t} x_{t-1}, \beta_t I)\]

With closed-form marginal:

\[q(x_t | x_0) = \mathcal{N}(x_t; \sqrt{\bar{\alpha}_t} x_0, (1-\bar{\alpha}_t) I)\]

where \(\bar{\alpha}_t = \prod_{s=1}^t (1-\beta_s)\).

2.2 Reverse Process

The reverse process learns to denoise:

\[p_\theta(x_{t-1} | x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \sigma_t^2 I)\]

2.3 Training Objective

The simplified objective predicts the noise:

\[\mathcal{L} = \mathbb{E}_{t, x_0, \epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]\]

2.4 What Must Change for Discrete Data

Concept Continuous Discrete
Corruption Add Gaussian noise Apply transition matrix
Stationary distribution \(\mathcal{N}(0, I)\) Uniform / all-[MASK]
Score function \(\nabla_x \log p(x)\) Log-ratios for state flips
Reverse step Gaussian sample Categorical sample
Reparameterization \(x = \mu + \sigma\epsilon\) Gumbel-Softmax / straight-through

3. Transition Matrices for Discrete Data

3.1 Discrete Forward Process

For a vocabulary of size \(K\), we represent tokens as one-hot vectors \(x \in \{0,1\}^K\). The forward process is defined by a sequence of transition matrices:

Definition: Discrete Forward Process

The forward process at step \(t\) is:

\[q(x_t | x_{t-1}) = \text{Cat}(x_t; p = x_{t-1} Q_t)\]

where \(Q_t \in \mathbb{R}^{K \times K}\) is a row-stochastic transition matrix, and \(Q_t[i,j]\) is the probability of transitioning from state \(i\) to state \(j\).

3.2 Cumulative Transition Matrix

The marginal distribution \(q(x_t | x_0)\) can be computed directly:

\[q(x_t | x_0) = \text{Cat}(x_t; p = x_0 \bar{Q}_t)\]

where the cumulative transition matrix is:

\[\bar{Q}_t = Q_1 Q_2 \cdots Q_t\]
Theorem: Marginal Probability

For one-hot encoded \(x_0 = e_i\) (the \(i\)-th basis vector), the probability of being in state \(j\) at time \(t\) is:

\[q(x_t = e_j | x_0 = e_i) = \bar{Q}_t[i, j]\]

3.3 Stationary Distribution

As \(t \to \infty\), the process should converge to a known stationary distribution \(\pi\) that is independent of \(x_0\):

\[\lim_{t \to \infty} \bar{Q}_t = \mathbf{1} \pi^T\]

where all rows of the limiting matrix equal \(\pi\). This requirement constrains the design of \(Q_t\).

3.4 Reverse Posterior

The true reverse posterior \(q(x_{t-1} | x_t, x_0)\) is tractable via Bayes' rule:

Theorem: Discrete Reverse Posterior
\[q(x_{t-1} | x_t, x_0) \propto q(x_t | x_{t-1}) \cdot q(x_{t-1} | x_0)\]

In categorical form:

\[q(x_{t-1} = e_k | x_t = e_j, x_0 = e_i) \propto Q_t[k, j] \cdot \bar{Q}_{t-1}[i, k]\]

The proportionality constant normalizes over \(k \in \{1, \ldots, K\}\).

4. D3PM: Discrete Denoising Diffusion

D3PM (Discrete Denoising Diffusion Probabilistic Models) by Austin et al. (2021) introduced a general framework for discrete diffusion with various transition matrix designs.

4.1 Uniform Transition

The simplest corruption strategy:

Definition: Uniform Transition Matrix
\[Q_t^{uniform} = (1 - \beta_t) I + \frac{\beta_t}{K} \mathbf{1}\mathbf{1}^T\]

With probability \((1-\beta_t)\), stay in place. Otherwise, jump to a uniformly random state (including possibly the current state).

Properties of uniform transition:

  • Stationary distribution: \(\pi = (1/K, \ldots, 1/K)\) (uniform)
  • Closed-form cumulative: \(\bar{Q}_t = \bar{\alpha}_t I + (1-\bar{\alpha}_t) \frac{1}{K}\mathbf{1}\mathbf{1}^T\)
  • Suitable for unordered categorical data

4.2 Absorbing Transition

Tokens transition to a special [MASK] state and stay there:

Definition: Absorbing Transition Matrix
\[Q_t^{absorbing}[i,j] = \begin{cases} 1 - \beta_t & \text{if } i = j \neq [\text{MASK}] \\ \beta_t & \text{if } j = [\text{MASK}] \text{ and } i \neq [\text{MASK}] \\ 1 & \text{if } i = j = [\text{MASK}] \\ 0 & \text{otherwise} \end{cases}\]

The [MASK] state is "absorbing"—once a token becomes [MASK], it stays [MASK].

Properties:

  • Stationary distribution: All mass on [MASK]
  • Cumulative: Each token independently masked with probability \(1 - \bar{\alpha}_t\)
  • Natural connection to masked language modeling

4.3 Discretized Gaussian Transition

For ordinal data (e.g., pixel values, discretized features), transitions can respect ordering:

Definition: Discretized Gaussian Transition
\[Q_t^{gaussian}[i,j] \propto \exp\left(-\frac{(i-j)^2}{2\sigma_t^2}\right)\]

Tokens are more likely to transition to nearby states. Row normalization ensures \(\sum_j Q_t[i,j] = 1\).

This is appropriate when states have inherent ordering (e.g., discrete intensity levels) and local corruption is more natural than random jumps.

4.4 Token Embedding Transition

For text, we can define transitions based on semantic similarity in embedding space:

\[Q_t[i,j] \propto \exp\left(-\frac{\|e_i - e_j\|^2}{2\sigma_t^2}\right)\]

where \(e_i, e_j\) are learned token embeddings. This encourages corruption to semantically similar tokens.

5. The Discrete ELBO

5.1 Variational Lower Bound

Following the standard derivation, the log-likelihood is lower-bounded:

Theorem: Discrete Diffusion ELBO
\[\log p_\theta(x_0) \geq \mathbb{E}_{q(x_{1:T}|x_0)}\left[\log \frac{p_\theta(x_{0:T})}{q(x_{1:T}|x_0)}\right]\]

Decomposing:

\[\mathcal{L}_{VLB} = \underbrace{D_{KL}(q(x_T|x_0) \| p(x_T))}_{\mathcal{L}_T} + \sum_{t=2}^{T} \underbrace{\mathbb{E}_{q(x_t|x_0)}[D_{KL}(q(x_{t-1}|x_t, x_0) \| p_\theta(x_{t-1}|x_t))]}_{\mathcal{L}_{t-1}} + \underbrace{\mathbb{E}_{q(x_1|x_0)}[-\log p_\theta(x_0|x_1)]}_{\mathcal{L}_0}\]

5.2 KL Divergence for Categoricals

For categorical distributions \(p\) and \(q\) over \(K\) states:

\[D_{KL}(q \| p) = \sum_{k=1}^{K} q_k \log \frac{q_k}{p_k}\]

This is well-defined and differentiable, enabling direct optimization of the ELBO.

5.3 Parameterization of Reverse Process

The model predicts a distribution over \(x_0\) given \(x_t\):

\[\tilde{p}_\theta(x_0 | x_t) = \text{softmax}(f_\theta(x_t, t))\]

The reverse distribution is then:

\[p_\theta(x_{t-1} | x_t) = \sum_{x_0} q(x_{t-1} | x_t, x_0) \tilde{p}_\theta(x_0 | x_t)\]

5.4 Auxiliary Denoising Loss

D3PM adds an auxiliary cross-entropy loss for stability:

\[\mathcal{L}_{aux} = \mathbb{E}_{t, x_0, x_t}[-\log \tilde{p}_\theta(x_0 | x_t)]\]

This directly supervises the model's prediction of the clean data.

5.5 Hybrid Loss

The final D3PM objective combines:

\[\mathcal{L}_{D3PM} = \mathcal{L}_{VLB} + \lambda \mathcal{L}_{aux}\]

The auxiliary loss provides dense supervision, especially helpful at high noise levels where the VLB terms become small.

6. MDLM: Masked Diffusion Language Models

MDLM (Masked Diffusion Language Models) by Sahoo et al. (2024) establishes a deep connection between masked language modeling and discrete diffusion.

6.1 Masking as Absorbing Diffusion

MDLM uses purely absorbing diffusion with a [MASK] token:

Definition: MDLM Forward Process

At time \(t\), each token is independently masked with probability \(1 - \alpha_t\):

\[q(x_t | x_0) = \alpha_t \cdot x_0 + (1 - \alpha_t) \cdot e_{[\text{MASK}]}\]

where \(\alpha_t \in [0, 1]\) is a decreasing schedule with \(\alpha_0 = 1\) and \(\alpha_T \approx 0\).

6.2 The Masked Schedule

MDLM uses a carefully designed masking schedule. The probability that a token remains unmasked at time \(t\) is:

\[\alpha_t = 1 - \frac{t}{T}\]

or more sophisticated schedules that control the rate of information destruction.

6.3 Connection to BERT

BERT training can be viewed as single-step discrete diffusion:

BERT as One-Step Diffusion
  • Forward: Randomly mask 15% of tokens
  • Reverse: Predict original tokens from masked input

MDLM generalizes this to multiple steps with a principled noise schedule, enabling iterative refinement during generation.

6.4 MDLM Training Objective

The simplified MDLM loss focuses on masked positions:

Definition: MDLM Loss
\[\mathcal{L}_{MDLM} = \mathbb{E}_{t, x_0, x_t}\left[\sum_{i: x_t^{(i)} = [\text{MASK}]} -\log p_\theta(x_0^{(i)} | x_t, t)\right]\]

Only compute loss on positions that are currently masked. The model predicts the original token at each masked position.

6.5 Theoretical Analysis

MDLM shows that under certain conditions, the simplified cross-entropy loss is a valid upper bound on the negative log-likelihood:

Theorem: MDLM ELBO Equivalence

For absorbing diffusion with independent masking, the simplified loss equals a weighted version of the ELBO:

\[\mathcal{L}_{MDLM} = \mathbb{E}_t\left[w_t \cdot \mathcal{L}_t\right]\]

where \(w_t\) depends on the masking schedule. With appropriate reweighting, this optimizes a tight bound on log-likelihood.

6.6 Low Discrepancy Sampling

MDLM proposes sampling timesteps using low-discrepancy sequences to reduce variance:

  • Instead of uniform random \(t \sim U(1, T)\), use quasi-random sequences
  • Better coverage of the timestep space per batch
  • Empirically improves convergence speed

7. SEDD: Score Entropy Discrete Diffusion

SEDD (Score Entropy Discrete Diffusion) by Lou et al. (2024) brings score matching ideas to discrete spaces, providing an alternative to likelihood-based training.

7.1 The Challenge of Discrete Scores

In continuous diffusion, the score \(\nabla_x \log p(x)\) is the gradient of log-density. For discrete data, there is no gradient—we need a different notion of "score."

7.2 Concrete Score Definition

Definition: Discrete Score (Concrete Score)

For discrete data \(x\) over vocabulary \(V\), define the score for changing position \(i\) from current value to value \(j\):

\[s(x)[i, j] = \log p(x^{i \to j}) - \log p(x)\]

where \(x^{i \to j}\) denotes \(x\) with position \(i\) changed to token \(j\).

This is the log-ratio of probabilities when flipping one token.

The score captures how much more (or less) likely the data becomes when we change a single token. This is the discrete analogue of the continuous gradient.

7.3 Properties of the Discrete Score

  • \(s(x)[i, x_i] = 0\) (no change from current value)
  • \(\sum_j \exp(s(x)[i,j]) \cdot p(x^{i \to j}) = p(x)\) (normalization)
  • The score uniquely determines the distribution (up to a constant)

7.4 Score Entropy Loss

SEDD trains by matching scores of the noisy data distribution:

Theorem: Score Entropy Objective

The SEDD loss is:

\[\mathcal{L}_{SEDD} = \mathbb{E}_{t, x_0, x_t}\left[\sum_{i, j} Q_t[x_t^{(i)}, j] \cdot \ell\left(s_\theta(x_t, t)[i, j], s^*(x_t, t)[i, j]\right)\right]\]

where \(s^*\) is the true score of the noisy distribution and \(\ell\) is a loss function (e.g., squared error or a robust alternative).

7.5 Denoising Score Matching for Discrete Data

The true score at time \(t\) can be expressed in terms of \(x_0\):

\[s^*(x_t, t)[i, j] = \log \frac{p(x_t^{i \to j}, t)}{p(x_t, t)} = \log \frac{\sum_{x_0} q(x_t^{i \to j} | x_0) p(x_0)}{\sum_{x_0} q(x_t | x_0) p(x_0)}\]

During training, we condition on the known \(x_0\), simplifying computation.

7.6 Ratio Matching Interpretation

SEDD can be viewed as learning probability ratios:

Ratio Matching View

The model learns \(r_\theta(x, i, j) \approx p(x^{i \to j}) / p(x)\). These ratios are sufficient for sampling via Gibbs-like procedures: propose a change, accept with probability based on the ratio.

7.7 SEDD Sampling

Sampling uses the learned scores to reverse the diffusion:

  1. Start from stationary distribution \(x_T \sim \pi\)
  2. At each step \(t\), compute transition probabilities from scores
  3. Sample next state \(x_{t-1}\) from this distribution

The transition probabilities are:

\[p(x_{t-1}^{(i)} = j | x_t) \propto \exp(s_\theta(x_t, t)[i, j]) \cdot R_t[x_t^{(i)}, j]\]

where \(R_t\) is a reverse rate matrix derived from the forward process.

8. Continuous-Time Formulation

8.1 From Discrete to Continuous Time

As \(T \to \infty\), discrete-time Markov chains converge to continuous-time Markov chains (CTMCs). This provides theoretical clarity and enables flexible time discretization during sampling.

8.2 Rate Matrix

Definition: Continuous-Time Markov Chain

A CTMC is characterized by a rate matrix \(R \in \mathbb{R}^{K \times K}\) where:

  • \(R[i, j] \geq 0\) for \(i \neq j\) (transition rates)
  • \(R[i, i] = -\sum_{j \neq i} R[i, j]\) (rows sum to zero)

The probability of being in state \(j\) at time \(t\) evolves as:

\[\frac{d}{dt} p(x_t = j) = \sum_i p(x_t = i) R[i, j]\]

8.3 Connection to Transition Matrices

The transition matrix over time interval \(\Delta t\) is:

\[Q(\Delta t) = \exp(\Delta t \cdot R) \approx I + \Delta t \cdot R\]

for small \(\Delta t\). This shows that discrete diffusion with small \(\beta_t\) approximates a CTMC.

8.4 Forward Rate for Common Transitions

Example: Absorbing Rate Matrix

For absorbing diffusion to [MASK] with rate \(\gamma(t)\):

\[R(t)[i, j] = \begin{cases} \gamma(t) & \text{if } j = [\text{MASK}], i \neq [\text{MASK}] \\ -\gamma(t) & \text{if } i = j \neq [\text{MASK}] \\ 0 & \text{otherwise} \end{cases}\]

8.5 Reverse-Time CTMC

The reverse process is also a CTMC with a different rate matrix:

Theorem: Reverse Rate Matrix

The reverse-time rate matrix is:

\[R^{reverse}(t)[i, j] = R(t)[j, i] \cdot \frac{p_t(j)}{p_t(i)}\]

where \(p_t\) is the marginal distribution at time \(t\). The reverse rate involves the probability ratio, connecting to the score function.

8.6 Advantages of Continuous Time

  • Theoretical elegance: Clean mathematical framework
  • Flexible discretization: Choose step sizes during sampling
  • Adaptive methods: Larger steps where dynamics are slow
  • Unified analysis: Common framework for different corruption types

9. Sampling Strategies

9.1 Ancestral Sampling

The basic approach follows the reverse Markov chain:

  1. Sample \(x_T\) from stationary distribution
  2. For \(t = T, T-1, \ldots, 1\): sample \(x_{t-1} \sim p_\theta(x_{t-1} | x_t)\)
  3. Return \(x_0\)

9.2 Tau-Leaping

For continuous-time models, tau-leaping takes larger time steps:

\[x(t - \tau) \sim \text{Multinomial based on rates } R^{reverse}(t) \cdot \tau\]

This approximates the CTMC dynamics over interval \(\tau\), trading accuracy for speed.

9.3 Predictor-Corrector

Alternating between prediction (reverse step) and correction (refinement):

  1. Predictor: Take a reverse diffusion step
  2. Corrector: Apply additional denoising (e.g., Gibbs sampling steps)

The corrector improves sample quality at the cost of additional computation.

9.4 Confidence-Based Decoding

For masked diffusion, selectively unmask based on model confidence:

Confidence-Based Unmasking
  1. Predict distribution over all [MASK] positions
  2. Compute confidence (e.g., max probability or entropy)
  3. Unmask the \(k\) most confident positions
  4. Repeat until all positions are unmasked

This allows the model to "commit" first to tokens it is certain about, using this context to inform harder decisions.

9.5 Parallel Decoding

Unlike autoregressive models, discrete diffusion can generate all positions in parallel:

  • Each step refines all positions simultaneously
  • Number of steps (not sequence length) determines latency
  • Typically 10-100 steps vs. \(L\) steps for autoregressive

10. Conditioning and Guidance

10.1 Classifier-Free Guidance

CFG extends naturally to discrete diffusion:

Definition: Discrete CFG

Train both conditional \(p_\theta(x_0 | x_t, c)\) and unconditional \(p_\theta(x_0 | x_t)\) (with condition \(c\) dropped randomly). At sampling:

\[\log \tilde{p}(x_0 | x_t, c) = \log p(x_0 | x_t) + w \cdot (\log p(x_0 | x_t, c) - \log p(x_0 | x_t))\]

Apply softmax to get the guided distribution.

10.2 Score Guidance

For SEDD, guidance modifies the discrete scores:

\[\tilde{s}(x, t, c) = s(x, t, \varnothing) + w \cdot (s(x, t, c) - s(x, t, \varnothing))\]

Higher \(w\) strengthens the condition's influence.

10.3 Infilling and Inpainting

Discrete diffusion naturally supports partial conditioning:

  • Prefix/suffix conditioning: Fix some positions, generate others
  • Infilling: Generate middle given beginning and end
  • Arbitrary masks: Condition on any subset of positions

Implementation: Never mask the conditioned positions during generation.

10.4 Span Corruption for Pre-training

Following T5, corrupt spans rather than individual tokens:

  1. Sample span lengths from a distribution
  2. Replace each span with a single [MASK] token
  3. Train to reconstruct the original spans

This encourages the model to learn longer-range dependencies.

11. Comparison with Continuous Diffusion

11.1 Fundamental Differences

Aspect Continuous Diffusion Discrete Diffusion
Data type Real-valued vectors Categorical tokens
Corruption Additive Gaussian noise Stochastic state transitions
Stationary dist. \(\mathcal{N}(0, I)\) Uniform or all-[MASK]
Score function \(\nabla_x \log p(x) \in \mathbb{R}^d\) Log-ratios \(\in \mathbb{R}^{L \times K}\)
Network output Predicted noise \(\epsilon\) Predicted logits/scores
Sampling Gaussian perturbation Categorical sampling

11.2 Embedding-Based Approaches

An alternative is to embed discrete tokens in continuous space:

  1. Embed tokens: \(z = \text{Embed}(x) \in \mathbb{R}^{L \times d}\)
  2. Apply continuous diffusion to \(z\)
  3. Decode: \(\hat{x} = \text{argmax Decode}(\hat{z})\)

This reuses continuous diffusion machinery but introduces embedding/decoding errors.

11.3 When to Use Each Approach

Practical Guidance
  • Discrete diffusion: Text, code, molecular structures, any symbolic data
  • Continuous diffusion: Images, audio, video, sensor data
  • Hybrid: VQ-VAE latents (discrete codes for visual/audio data)

11.4 Perplexity vs. Generation Quality

Discrete diffusion models can be evaluated on:

  • Perplexity: Via the ELBO (comparable to autoregressive models)
  • Generation quality: Human evaluation, downstream task performance
  • Controllability: Ability to satisfy constraints via conditioning

Recent work (MDLM, SEDD) shows discrete diffusion approaching autoregressive perplexity while offering better controllability.

11.5 Computational Tradeoffs

Model Type Training Generation
Autoregressive \(O(L)\) per token, sequential \(O(L^2)\) total, sequential
Discrete Diffusion \(O(L)\) parallel \(O(TL)\) with \(T\) steps, parallel

Discrete diffusion trades more forward passes (\(T\) steps) for full parallelism within each step, favorable for batch generation on modern accelerators.
