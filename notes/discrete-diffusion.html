1. Introduction

Standard diffusion models add Gaussian noise to continuous data (images). But much of the world's data is discrete: text, code, molecules, DNA sequences. How do we apply diffusion to categorical data?

Key Challenge

We cannot add Gaussian noise to discrete tokens. Instead, we must define a transition process over discrete states that gradually destroys information.

This note covers three major approaches: D3PM (general transition matrices), MDLM (masking as diffusion), and SEDD (score matching for discrete data).

2. Transition Matrices

2.1 Discrete Forward Process

For a vocabulary of size \(K\), we define the forward process via a transition matrix \(Q_t \in \mathbb{R}^{K \times K}\):

Definition: Discrete Forward Process
\[q(x_t | x_{t-1}) = \text{Cat}(x_t; p = x_{t-1} Q_t)\]

where \(x_t \in \{0,1\}^K\) is a one-hot vector and \(Q_t[i,j]\) is the probability of transitioning from state \(i\) to state \(j\) at step \(t\).

2.2 Cumulative Transition

We can jump directly from \(x_0\) to \(x_t\):

\[q(x_t | x_0) = \text{Cat}(x_t; p = x_0 \bar{Q}_t) \quad \text{where} \quad \bar{Q}_t = Q_1 Q_2 \cdots Q_t\]

2.3 Stationary Distribution

As \(t \to \infty\), the process should converge to a known distribution \(\pi\) (e.g., uniform). This requires \(\bar{Q}_\infty\) to have all rows equal to \(\pi\).

3. D3PM

Discrete Denoising Diffusion Probabilistic Models (Austin et al., 2021) explores different transition matrix designs:

3.1 Uniform Transition

\[Q_t = (1 - \beta_t) I + \frac{\beta_t}{K} \mathbf{1}\mathbf{1}^\top\]

With probability \((1-\beta_t)\), stay in place. Otherwise, jump to a uniformly random state.

3.2 Absorbing Transition

\[Q_t[i,j] = \begin{cases} 1 - \beta_t & \text{if } i = j \neq [\text{MASK}] \\ \beta_t & \text{if } j = [\text{MASK}] \\ 1 & \text{if } i = j = [\text{MASK}] \\ 0 & \text{otherwise} \end{cases}\]

Tokens gradually transition to a special [MASK] state. The stationary distribution is all [MASK] tokens.

3.3 Gaussian Transition (Discretized)

For ordinal data, we can define transitions based on a discretized Gaussian:

\[Q_t[i,j] \propto \exp\left(-\frac{(i-j)^2}{2\sigma_t^2}\right)\]

This is natural for data like pixel values where neighboring states are similar.

3.4 D3PM Loss

The ELBO decomposes similarly to DDPM:

\[L = L_0 + \sum_{t=2}^T L_{t-1} + L_T\]

where each \(L_{t-1}\) is a KL divergence between categorical distributions.

4. MDLM

Masked Diffusion Language Models (Sahoo et al., 2024) reinterprets BERT-style masking as a diffusion process:

Definition: Masking as Diffusion

The forward process is pure absorbing diffusion into [MASK]. At time \(t\), each token is independently masked with probability \(1 - \bar{\alpha}_t\):

\[q(x_t | x_0) = \bar{\alpha}_t \cdot x_0 + (1 - \bar{\alpha}_t) \cdot e_{\text{[MASK]}}\]

4.1 Connection to BERT

BERT training = one-step denoising. MDLM = multi-step denoising with a noise schedule. The key insight is that MLM (masked language modeling) is a special case of discrete diffusion.

4.2 Simplified Loss

MDLM uses a simple cross-entropy loss on masked positions:

\[L = \mathbb{E}_{t, x_0, x_t}\left[-\log p_\theta(x_0 | x_t, t)\right]\]

5. SEDD

Score Entropy Discrete Diffusion (Lou et al., 2024) brings score-matching ideas to discrete data:

5.1 Discrete Score Function

In continuous diffusion, we learn \(\nabla_x \log p(x)\). For discrete data, we define a concrete score:

Definition: Discrete Score
\[s_\theta(x, t)[i,j] = \log \frac{p_\theta(x^{i \to j}_t | t)}{p_\theta(x_t | t)}\]

The score captures the log-ratio of probabilities when we flip token at position \(i\) from its current value to value \(j\).

5.2 Score Entropy Loss

SEDD trains with a score entropy objective that generalizes denoising score matching:

\[L = \mathbb{E}_{t, x_0, x_t}\left[\sum_j Q_t[x_t, j] \left(s_\theta(x_t, t)[j] - \log Q_t[x_t, j] + \log Q_t[x_0, j]\right)^2\right]\]

5.3 Sampling

At each step, compute transition probabilities proportional to the exponentiated score and sample from this distribution.

6. Connections to Continuous Diffusion

Concept Continuous Discrete
Forward process Add Gaussian noise Apply transition matrix
Stationary dist. \(\mathcal{N}(0, I)\) Uniform / all [MASK]
Score \(\nabla_x \log p(x)\) Log-ratio for flips
Reverse step Gaussian + predicted mean Categorical sampling

6.1 Continuous-Time Limit

As the number of steps \(T \to \infty\), discrete diffusion converges to a continuous-time Markov chain (CTMC). The transition rates are given by a rate matrix \(R\) where \(R_{ij}\) is the instantaneous probability of jumping from \(i\) to \(j\).

6.2 Guidance

Classifier-free guidance extends naturally to discrete diffusion by interpolating conditional and unconditional scores:

\[\tilde{s}(x, t, c) = s(x, t, \varnothing) + w \cdot (s(x, t, c) - s(x, t, \varnothing))\]
